# Control map — SOC 2 and GDPR readiness (56-18)

Plan source: `docs/planning/04-SECURITY-PRIVACY.md` §12 (Phase 1 GDPR-ready controls, Phase 2 SOC 2
Type I then Type II) and `docs/planning/33-LEGAL-AND-COMPLIANCE-REQUIREMENTS.md` §3–§12. The plan
names no other privacy law, so this map covers SOC 2 and GDPR only.

This is a **readiness** map, graded from the code on 2026-11-16. TManage is not SOC 2 audited and
is not certified against anything. "Met" means the control exists in code or a runbook and the path
below shows it; it does not mean an auditor has tested it.

Status key: **Met** = built and evidenced; **Partial** = built in part, or built but never exercised
or recorded; **Gap** = not built, or a policy/people/auditor item with nothing in the repository.
