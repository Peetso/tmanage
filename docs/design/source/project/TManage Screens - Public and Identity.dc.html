PUB-05 · SECURITY & TRUST · ARCHITECTURE SUMMARY, DOCUMENTS, STATUS · 1440×720
SECURITY & TRUST
Two tenants can never see each other.
Isolation is enforced in the database, not in the interface. Every list, ID lookup, search index, file URL, notification, realtime channel and audit query is scoped to one organization, and we test that a user of one tenant cannot reach another through any of those paths.
