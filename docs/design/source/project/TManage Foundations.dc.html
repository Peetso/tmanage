TManage design system
LIMEFRAME
Neo-editorial work OS. A near-monochrome foundation of ink, warm paper and concrete, with acid lime carrying one meaning only: current, next, live. Scale and geometry make hierarchy; colour is not asked to do that job.
north star · assets/references/TManage-primary-visual-reference.webp
field proportion target · 80% neutral / 15% lime / 5% semantic
Three principles that keep it from becoming a dashboard
01
Time is an object
Schedules, milestones, versions and client journeys are all the same physical track. Position means progress; lime means now.
02
One action dominates
Every screen has a single black capsule that is obviously the next move, and states why now beside it.
03
Audience is never implicit
Internal, client visible and client action required always read as text, shape and colour together. New content defaults internal.

Rules
Satoshi Variable for Latin display and interface, Manrope Variable for Latin paragraph copy, Alexandria Variable for Arabic, Geist Mono for identifiers, hashes and time codes.
Weight contrast before colour contrast. Negative tracking on Latin display only — never on Arabic.
Updating figures use tabular numerals so the layout does not twitch.
Minimum operational text 12px at weight 500; thin display weights are prohibited below 20px.

Brand lockup
Primary lockup, ink on paper. Marketing pages, sign-in, the onboarding welcome and any document cover. Minimum height 20px; clear space equal to the height of the mark on all sides.
Paper on dark. The lime wordmark exists but is reserved for one-colour print and merchandise — lime never carries the name inside the product, where it means current or next.
orb · in-app
Inside the product the mark appears as an ink orb with the lime glyph — never the wordmark, which would compete with the project name in every header.
Line and focus
1px quiet line
1.5px structural
focus-visible · 2px ink + 3px lime
Depth order
Plane contrast first, overlap second, outline third, shadow last. Shadow is only for true overlays: dialogs, sheets, the Context Lens when floating, command surface.
CONTEXT LENS
Dark panel overlaps the light canvas — it never becomes a second permanent column.
