## Definition of each status here
- **mapped** — template, composition, role, primary action, key data, visibility rule, required states named.
- **wireframed** — regions and hierarchy drawn, not yet in Limeframe fidelity.
- **visual_system_applied** — high-fidelity Limeframe screen exists in a .dc.html artifact.
- **states_complete** — populated plus the relevant empty/loading/error/permission/conflict states drawn.
- **responsive_complete** — mobile (and where relevant tablet) composition drawn, not scaled.
- **rtl_complete** — Arabic content, semantic mirroring and mixed-direction isolation drawn.
- **a11y_reviewed** — keyboard path, focus order, SR order and non-drag alternative documented.
- **prototype_linked** — reachable inside a connected flow in `prototype-map.md`.
- **dev_ready** — contract, tokens, states and acceptance mapping signed off in `developer-handoff.md`.
