# Pattern — Client Preview / Projection

**Problem.** "Preview as client" is usually the internal screen with controls hidden — which is both a
lie and a leak.

**How it works here.** The preview renders the *real allowlisted projection* for a named client role.
Anything not in the projection is not rendered at all — no hidden nodes, no disabled ghosts.

**Frame shift.** Internal orbital rail disappears; the portal frame appears (paper canvas, larger type,
lime progress track, very few controls). A persistent black capsule names the role being previewed and
the exit action.

**Publish safety check (DEL-04).** Recipients with authority · exclusions (internal comments, cost
fields, prior versions) · warnings for links to internal-only objects · the live projection · one
primary action. Publication is blocked while an unresolved internal link exists.

**Freshness.** The projection states when it was generated; a stale projection (>5 min or after an edit)
must be regenerated before publishing.
