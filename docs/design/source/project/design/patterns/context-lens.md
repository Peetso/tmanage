# Pattern — Context Lens

**Problem.** Relationships, source, access and history are what make the work graph valuable, and they
do not fit inside a row.

**Modes.** `pinned` 360px light sheet on ≥1440px · `overlay` dark panel that crosses the canvas edge for
high-focus context (meeting summary, AI evidence, approval consequence) · `sheet` bottom sheet ≤760px.

**Content order.** subject identity → audience → dates → version → source → relationships → story → one
action. Never a second navigation column.

**Rules.** Always dismissible. Never contains the only path to an action. Dark tone is reserved for
summary/consequence/media contexts so it stays meaningful rather than decorative.
