# Pattern — Audience Halo

**Problem.** Every leak in client collaboration starts with an ambiguous audience.

**Variants and fixed copy (file 19).**
- Internal — "Only your team can see this." ring: solid ink, glyph ■
- Client visible — "Related client members can see this after publication." ring: violet, glyph ◎
- Client action required — "Selected client members will be asked to act." lime field, ink ring, glyph !
- Mixed — thread contains both audiences; the composer states the effective audience before sending.
- Conflict — dashed danger ring, glyph ≠, blocks publication until resolved.

**Rules.** New content defaults internal. Converting a client-visible message to work does *not* inherit
client visibility — the inherited-access warning is shown instead. The halo appears wherever an object
can be shared: rows, cards, composer, publish check, portal.
