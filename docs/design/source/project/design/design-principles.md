# TManage — Design Principles (Limeframe)

1. **Time is an object.** Schedules, milestones, request states, governed versions and client journeys
   are all the same Pulse Track grammar: ink = confirmed history, lime = now/next, outline = future.
   Position carries meaning, and every track has an ordered text equivalent.
2. **One action dominates.** Each surface has exactly one black Focus Capsule that names the next move
   and says why now. Everything else is quieter by construction.
3. **Audience is never implicit.** Internal / client visible / client action required always read as
   text + shape + colour. New content defaults internal. Publication is an explicit, previewed act.
4. **Progress is evidence, not arithmetic.** Milestones advance on evidence; a task average is never
   presented as progress. Desired, forecast and committed dates are visually and verbally distinct.
5. **Scale makes hierarchy; colour does not.** Four neutral fields plus one lime. Semantic colour is a
   few pixels wide and always paired with a word.
6. **Density is a mode, not a compromise.** Editorial, balanced and operational share type, palette,
   orbs, capsules and line. A 214-row list is as much Limeframe as the Home hero.
7. **Depth by plane, overlap and outline.** Shadow only for true overlays. No glass, no gradient wash.
8. **The client mode is a product, not a permission filter.** The portal is generated from the real
   allowlisted projection — never the internal UI with controls hidden.
9. **No scoring of people.** Insights report exceptions and system causes, never individual output.
10. **Accessible by default.** Ink on lime only, 44px mobile targets, keyboard parity for every drag,
    labels on every orb, reduced-motion equivalents, WCAG 2.2 AA as a floor.
