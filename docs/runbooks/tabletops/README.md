# Incident tabletops (56-13)

One hour, once a quarter. Play one scenario from `../incident-response.md` section 6 against the
runbook with a timer. Nothing in production changes.

Record each one as `YYYY-MM.md` in this folder with:

1. **Date, people, scenario.**
2. **Timeline.** When each runbook step was reached.
3. **Where we got stuck.** Missing access, unclear steps, a template that did not fit.
4. **Changes.** What was changed in the runbook or templates, with the commit.
5. **Next scenario.**
