# Authority notice (56-13)

Use when an authority clock applies (see `../incident-response.md` section 3). Most authorities
have an online form; paste these answers into it. Send within 72 hours of `{{detected_at}}`. If
some facts are still unknown, send what you have and say a follow-up will come (GDPR Art. 33(4)
allows this).
