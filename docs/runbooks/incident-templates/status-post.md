# Status post (56-13)

The public status page shows only: component, status, title, the write-up below, started and
resolved. Never name an organization, a person, a country or a data category here. Update the
write-up at each status change, then Publish.

## English

**Title:** {{incident_title}}

- **Investigating:** We are looking into a problem with {{component}} that started at
  {{started_at}}. Next update by {{next_update_at}}.
- **Identified:** We found the cause and are fixing it. {{plain_cause}}
- **Monitoring:** The fix is live. We are watching to make sure it holds.
- **Resolved:** {{component}} has worked normally since {{resolved_at}}. We are sorry for the
  trouble.

## العربية

**العنوان:** {{incident_title}}

- **قيد التحقيق:** نتحقق من مشكلة في {{component}} بدأت في {{started_at}}. التحديث التالي قبل
  {{next_update_at}}.
- **تحدد السبب:** وجدنا السبب ونعمل على إصلاحه. {{plain_cause}}
- **قيد المتابعة:** أصبح الإصلاح فعّالًا. نتابع للتأكد من ثباته.
- **تم الحل:** يعمل {{component}} بشكل طبيعي منذ {{resolved_at}}. نعتذر عن الإزعاج.
