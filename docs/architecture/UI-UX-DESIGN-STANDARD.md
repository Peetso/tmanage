# TManage UI/UX Design Standard

**Status:** binding (Peter, ABSOLUTE RULE, 2026-11-20). **Version** 1.0, 2026-11-20.
**Scope:** every screen, component, token, copy string and interaction in `apps/web`, `packages/ui`, `apps/desktop`, and the Figma file `ZdUCRiqBiT7s3u08HA28RO` (design-system page `0:1`).
**Companion to:** `ENGINEERING-STANDARD.md`. It uses the same row format: ID, rule, why/source, Today (`file:line`), Target, Check (**E** exists / **B** to build). Its checks are listed in `FITNESS-FUNCTIONS.md` §UX.

**Design-source order** (memory rules "Figma is the design", "UI exactly as designed"):

1. Figma `ZdUCRiqBiT7s3u08HA28RO`.
2. The design export `docs/design/source/project/design/tokens/tokens.json` and the `.dc.html` screens. The code treats these as immutable source material.
3. `packages/ui` (tokens + 23 components + Storybook + VR).
4. `apps/web`.

The code never leads the design. A code change that alters a design is first made in Figma.

## 6. Persona-based UX evaluation (Peter's required method)

Source rule: `D:/TManage/work/PETER-RULES.md:67-83` (2026-11-14). Method grounded in personas (U16 Cooper), journey mapping (U16 NN/g), SEQ and SUS (U16), WCAG 2.2 (U3), ISO 9241-110 (U1) and Nielsen (U6).

1. **Personas** (TManage roles from `docs/planning/09-MVP-PRD.md:15` plus Peter's list). Each is run in **English and Arabic**, on desktop and mobile width:
   - agency owner (Organization Owner)
   - project manager
   - team member
   - freelancer
   - client (Client Admin, Client Reviewer, Client Viewer)
2. **Journey.** Each persona gets a real goal and walks the whole path, from sign-in to the goal and its end state. The evaluator writes down every step, every pause to think, and every recovery from an error. Client journeys are tested first (memory "File viewer is mainly for clients").
3. **Score each journey on three axes, 1–5, with findings:**

| Axis          | What is checked (from PETER-RULES:81-83)                                                                                | Instruments                                                                                                                                        |
| ------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accessibility | keyboard-only, visible focus, screen-reader names, contrast, text size and 200 % zoom, target size, reduced motion, RTL | UX-4…UX-10, axe run, keyboard walk                                                                                                                 |
| Ease of use   | steps and thinking per task; a first-time user finds it without help; error recovery                                    | step count; **SEQ** (1–7) per task; **SUS** per persona per pass (proposed target ≥ 80; SUS ≥ 68 is the commonly cited average, source unverified) |
| Friendliness  | warm, plain wording; calm empty and error states; nothing intimidating or technical                                     | `copy-rules.md`, copy-lint warnings, H8/H9                                                                                                         |

4. **Findings.** Each finding has: persona, step, screenshot, the principle it breaks (ISO 9241-110 principle / H1–H10 / L1–L8 / WCAG SC), severity (0–4, Nielsen severity scale; source not separately verified), the recommended better design and why, and the rule ID.
5. **Ranked recommendations**: by severity × number of personas affected. The report answers the question "is this the best design for this person?", not only "does it work?".
6. **Output:** `D:/TManage/work/<pass>/UX-EVAL-<feature>.md`. Fixes go to Figma first (memory "Figma first, then live"), then to code.

| ID    | Rule                                                                                                                            | Check                                                                                                                                 |
