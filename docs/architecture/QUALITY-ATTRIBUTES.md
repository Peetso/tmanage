# TManage quality-attribute scenarios

The format is the six-part quality-attribute scenario from Bass, Clements and Kazman, _Software Architecture in Practice_, 4th ed., Ch. 3 (S23 in `ENGINEERING-STANDARD.md` §1). Characteristic names follow ISO/IEC 25010:2023 (S1).

**Every target number here is _proposed_.** None has been measured on the live host yet. `docs/ops/hostinger-profile.md` shows every gauge as "planning". A proposed number becomes binding only after it has been measured once (OB-1) and accepted in an ADR.

Each scenario has an ID (`QA-*`). Designs cite them (QM-1), and each one maps to the fitness function that proves it.
